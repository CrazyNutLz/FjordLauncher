# 魔改版更新记录

## 11.0.3.10 — 2026-09-08

- 帮助菜单的“查看客户端更新说明”替换为“检查启动器更新”，直接复用现有启动器自更新检查流程，方便手动测试。
- 移除完成提示中指向旧菜单的文字，保留游戏/更新操作互斥。

## 11.0.3.9 — 2026-09-08

- 底部状态栏分为实例信息、总游玩时长和更新状态三段，增加内边距、段间距与分隔线。
- 缩短完成提示文字，避免游玩时长与更新结果挤在一起。

## 11.0.3.8 — 2026-09-08

- 用户确认过的非静默更新成功后弹出完成提示；纯静默、无变更及失败时不弹成功提示，手动检查遵循同样规则。
- 底部状态栏持续显示下载百分比/大小、解压及安装进度，完成、无更新和失败结果保留显示。

## 11.0.3.7 — 2026-09-07

- 每条文件、ZIP、删除规则均可配置 notice、force、silent，未填写时继承顶层默认值。
- 按本机实际差异汇总去重说明和文件列表，只用待更新条目决定是否弹窗及是否强制；已完成历史更新不重复提示。
- 保存本次完整摘要供查看，长列表支持展开；补充累计清单维护说明及十次累计更新回归测试。

## 11.0.3.6 — 2026-09-07

- files/remove/archives 每条规则可独立配置 silent，省略时继承顶层默认值，仅提示发生变更的非静默文件。
- 新增顶层 force 强制更新；确认框只保留确定，禁止 Esc、关闭按钮和菜单取消跳过，可与静默更新组合。
- 清单生成脚本、文档和回归测试同步支持新字段。

## 11.0.3.5 — 2026-09-07

- 启动器打开后自动检查并应用客户端更新，移除实例启用开关和绑定要求。
- API 的文件、删除目录与 ZIP 目标统一相对于启动器数据目录，可直接指定实例路径和启动器目录文件。
- 数据目录整体更新与游戏运行互斥；更新失败或取消后，手动修复成功才允许启动游戏。
- 更新清单生成、打包脚本与文档同步采用新的根目录规则。

## 11.0.3.4 — 2026-09-07

- 客户端文件和 ZIP 支持 HTTP/HTTPS 下载及两种协议间的重定向，兼容 HTTP AList。
- 清单生成脚本同步支持 HTTP 地址；保留 SHA-256 校验，清单接口继续使用 HTTPS。
- 补充实例绑定与相对路径说明。

## 11.0.3.3 — 2026-09-07

- 新增客户端文件自动更新：SHA-256 校验、managed/seed 策略、文件名精确/包含删除和 ZIP 更新。
- 支持静默模式、实例绑定、手动检查/修复、进度展示与更新说明。
- 更新期间拦截游戏启动，实例跨进程互斥，文件安装支持备份和中断恢复。
- 增加发布清单生成脚本，完整客户端打包时绑定指定实例并排除本地更新状态。

魔改发布版本维护 `CMakeLists.txt` 的 `Launcher_VERSION_DOWNSTREAM`，本次从 2 升到 3；上游版本段保持 11.0.3。构建的 EXE 使用该统一版本，后续功能/修复发布同步增加末段并记录变更。
